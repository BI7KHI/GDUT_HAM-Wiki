# GDUT_HAM-Wiki

广东工业大学无线电社 Wiki 是一个基于 **Wiki.js** 搭建、内容托管在 **GitHub** 的业余无线电知识库，服务于社团建设、技术分享与校园生活经验沉淀。

> 🌐 站点地址：<https://argdut.bi7khi.xyz/>
> 📦 源码仓库：<https://github.com/BI7KHI/GDUT_HAM-Wiki>

## 内容板块

- **新手入门**：操作证考试、设台、呼号申请
- **技术知识库**：VNA、DMR、TDMA、电台维修
- **工具与软件**：QRZ、题库、卫星追踪、日志软件
- **校园生活**：大学城食堂、快递、就医、宿舍
- **学习笔记**：广工课程复习资料
- **计算机与 AI**：Git、计算机通识、AI 名词速查

完整导航见 [Wiki 首页](/zh/home)。

## 仓库结构

```text
zh/                  # Wiki.js 页面（Markdown）
avatars/             # 成员头像
dmr-digi/            # DMR 注册流程图片
radio-indoor/        # 设台流程图片
ham-tools/           # 工具类页面配图
```
