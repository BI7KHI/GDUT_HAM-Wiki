# 学习笔记导航

社团维护着一个基于 Obsidian 的共享知识笔记仓库 **GDUT-REVIEW-NOTES**，收录各贡献者的课程复习笔记，支持在线浏览、下载 PDF 或克隆到本地。

> 📚 一份陪你从入学到毕业的「广工自用复习笔记」仓库。

## 🎯 仓库定位

- **适用人群**：想快速入门或复习对应课程的同学。
- **内容特点**：课堂 PPT 提炼 + 截图补充。
- **包含课程**：各贡献者的在校课程，以理工科为主，包含部分公共课；不含个人选修课。
- **使用方式**：在线浏览 / 下载 PDF / 克隆到本地，适合考前系统复习。

## 📦 快速开始

### 1. 克隆整个仓库

```bash
git clone https://github.com/Kyunana097/GDUT-REVIEW-NOTES.git
```

### 2. 进入对应课程目录

```bash
cd GDUT-REVIEW-NOTES/NOTES
```

也可以在 GitHub 网页端直接浏览，或下载 PDF 版本。

## 🤝 贡献指南

1. Fork 仓库并新建分支。
2. 按“课程-章节-日期”命名文件，例如 `复变-留数定理-20251118`。
3. 提交 Pull Request，并简要说明内容来源和覆盖范围。
4. 更新对应课程根目录 README 中的「进度」栏。

> ⚠️ 如笔记包含教师 PPT 截图，请对版权页打码；原创板书和整理内容可正常上传。
