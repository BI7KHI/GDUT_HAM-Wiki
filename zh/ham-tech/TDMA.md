# TDMA 时分多址

**时分多址**（Time Division Multiple Access，TDMA）是一种多址接入技术：多个用户共享同一个载波频率，但被分配到**不同的时间片（时隙，Slot）**，轮流发送数据。

它与时分复用（TDM）思路相近，区别在于 TDM 通常指把一条链路的容量划分给多路信号，而 TDMA 强调多个**独立用户/终端**如何接入同一个无线信道。

## 工作原理

TDMA 把时间划分为周期性的**帧（Frame）**，每帧再划分为若干**时隙**。每个用户在属于自己的时隙内发射，其余时间保持静默：

```text
时间 →
┌─────────┬─────────┬─────────┬─────────┐
│ Slot 1  │ Slot 2  │ Slot 3  │ Slot 4  │   第 N 帧
├─────────┼─────────┼─────────┼─────────┤
│ 用户 A  │ 用户 B  │ 用户 C  │ 用户 D  │
└─────────┴─────────┴─────────┴─────────┘
        └────────── 帧周期 ──────────┘
```

为了保证各用户互不重叠，系统需要：

- **同步**：所有终端与基站保持统一的时间基准；
- **保护间隔（Guard Time）**：吸收传播时延和时钟误差，避免相邻时隙串扰；
- **突发（Burst）结构**：每个时隙内包含同步序列、控制信息和用户数据。

## 主要特点

**优点**

- 多个用户共享一个载波频率，频谱利用率较高；
- 非连续发射，终端在空闲时隙可以接收、测量或切换到其他信道；
- 时隙可按需动态分配，便于支持不同速率的数据业务；
- 相比 CDMA，功率控制要求相对宽松，实现复杂度较低。

**缺点**

- 需要精确的同步，系统开销较大；
- 时隙之间必须留出保护间隔，高速或远距离场景下效率下降；
- 突发发射对功放的线性度和峰值功率提出更高要求；
- 多径时延扩展可能造成时隙间干扰（ISI）。

## 与其他多址方式的比较

| 方式 | 区分用户的维度 | 典型例子 | 特点 |
|------|----------------|----------|------|
| FDMA | 频率 | 模拟对讲机、早期蜂窝网 | 实现简单，但每个用户独占一段频率 |
| TDMA | 时间 | GSM、DMR、P25 Phase 2 | 共享频率，需要同步 |
| CDMA | 码字 | 3G、部分军用/卫星系统 | 抗干扰强，但存在远近效应 |
| OFDMA | 频率 + 时间 | LTE、5G、Wi-Fi 6 | 资源调度灵活，峰均比高 |

实际系统常组合使用多种多址方式，例如 GSM 就是 **FDMA + TDMA**：先按频率划分信道，再在每个信道上划分 8 个时隙。

## 在业余无线电中的应用

### DMR 数字对讲

DMR Tier II/III 是业余无线电中最常见的 TDMA 应用：

- 信道带宽 **12.5 kHz**；
- 每个信道划分为 **2 个时隙**，每个时隙 **30 ms**，一帧 **60 ms**；
- 采用 **4FSK** 调制，符号速率 4800 Bd，每符号 2 bit，总速率约 **9.6 kbit/s**；
- 两个时隙可以承载两路独立语音或数据，相当于在 12.5 kHz 带宽内提供两个逻辑信道。

> 在中继模式下，两个时隙通常一个用于上行、一个用于下行（具体分配由中继台配置决定）；直通模式下，终端也可以直接使用任一时隙。详细帧结构见 [DMR 数字通信入门](/zh/ham-tech/DMR)。
