# 矢量网络分析仪（VNA）

矢量网络分析仪（Vector Network Analyzer，VNA）是一种用于测量射频器件**反射**与**传输**特性的仪器。它可以测量天线、馈线、滤波器、功分器、双工器等器件在宽频带内的 **S 参数**，是业余无线电天馈系统调试中最实用的工具之一。

## 基本概念

### S 参数

S 参数（Scattering parameters）用入射波与反射波的关系描述一个射频网络：

| 参数 | 含义 | 业余无线电中的典型用途 |
|------|------|------------------------|
| **S11 / S22** | 输入/输出端反射系数 | 天线驻波比、回波损耗、阻抗匹配 |
| **S21** | 正向传输系数 | 滤波器插损、放大器增益、馈线损耗 |
| **S12** | 反向传输系数 | 隔离度、双向器件特性 |

### 驻波比与回波损耗

VNA 通常同时给出**驻波比（SWR/VSWR）**、**回波损耗（Return Loss）**和 **Smith 圆图**。三者描述的是同一件事，只是表达方式不同：

| 回波损耗 | 反射系数模值 | 近似驻波比 | 参考判断 |
|----------|--------------|------------|----------|
| -10 dB | 0.316 | 约 1.9 | 可用，但匹配一般 |
| -14 dB | 0.200 | 约 1.5 | 良好 |
| -20 dB | 0.100 | 约 1.22 | 优秀 |
| -26 dB | 0.050 | 约 1.11 | 非常优秀 |

> 业余天线通常以 **SWR < 1.5** 作为良好匹配的参考；短波天线在带宽边缘 SWR 升高属于正常现象。

## 在业余无线电中的用途

- **天线调试**：找到谐振频率、测量可用带宽、判断是否需要调整振子长度。
- **馈线检查**：测量电缆插入损耗，排查接头进水、氧化或线缆损坏。
- **滤波器/双工器调校**：观察通带插损、阻带抑制和端口隔离。
- **匹配网络验证**：用 Smith 圆图观察阻抗变化，指导 LC 匹配网络调整。

## 校准（Calibration）

校准是把测量参考面从仪器端口移到**测试电缆末端**的过程。未校准的测量结果会包含测试电缆本身的损耗和反射，不能直接用于判断天线性能。

单端口（S11）测量通常使用 **SOL 校准**：

1. 设置好起始/终止频率、扫描点数与中频带宽。
2. 在测试电缆末端依次接入 **Short（短路）**、**Open（开路）**、**Load（50 Ω 负载）** 标准件。
3. 每个标准件测量完成后保存校准数据。
4. 校准完成后不要更换测试电缆或改变其弯曲状态，否则需要重新校准。

双端口器件（如滤波器、放大器）还需要做 **Thru（直通）** 校准，部分仪器还需要隔离校准。

> ⚠️ **注意**：校准标准件的质量直接决定测量精度。廉价 VNA 自带的校准件在短波段通常够用，测量 VHF/UHF 以上频段时应尽量使用质量更好的校准件。

## NanoVNA 实操流程

以常见的 NanoVNA 为例，测量一副 VHF/UHF 天线：

1. **设置频率范围**：例如 140–150 MHz 或 430–440 MHz，扫描点数设为 101 或 201。
2. **执行校准**：在测试电缆末端完成 OPEN / SHORT / LOAD 校准并保存。
3. **连接天线**：将天线通过转接头接到校准后的电缆末端。
4. **读取数据**：
   - 在 `SWR` 界面找到驻波最低点，即天线谐振频率；
   - 在 `Smith` 界面观察阻抗是否接近 50 Ω；
   - 在 `Return Loss` 界面查看回波损耗。
5. **记录结果**：保存截图或导出 Touchstone（`.s1p`）文件，便于前后对比。

### 常见问题

| 现象 | 可能原因 |
|------|----------|
| 全频段 SWR 都很高 | 天线未连接、接头开路、电缆断裂 |
| SWR 曲线随手的接近而变化 | 未做校准或校准面不在天线端、天线受人体影响 |
| 测量结果与预期偏差大 | 校准件不合格、转接头损耗、频率范围设置错误 |
| 谐振点偏移 | 天线长度、周围环境或安装高度变化 |

## 使用注意事项

- **严禁在发射状态下连接 VNA**：先断开电台，确认无射频功率输入。
- 注意接口类型与转接头质量，劣质转接头会引入额外损耗和反射。
- 避免静电和强电磁环境，测量时保持设备良好接地。
- 低端 VNA 的绝对精度有限，更适合**相对比较**（改前/改后、不同天线之间），而不是实验室级计量。
